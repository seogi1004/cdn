4. 하이브리드 AI (PM2 Persistent)

Updated v10.5

Ollama를 서비스 대신 PM2로 관리하여 환경변수를 영구화합니다.

Terminal (alvin) 
brew install ollama
npm install -g pm2

# 기존 서비스 중지 (충돌 방지)
brew services stop ollama

# PM2로 Ollama 실행 (외부접속 허용, 병렬처리 4)
pm2 start "ollama serve" --name ollama-core \
  --env OLLAMA_HOST="0.0.0.0:11434" \
  --env OLLAMA_NUM_PARALLEL="4" \
  --env OLLAMA_KEEP_ALIVE="24h"

# 2026 모델 다운로드
ollama pull deepseek-r1:32b
ollama pull llama3.3
