6. AI 인프라 (64GB Optimized)

Tuned for M4 Pro

64GB 램의 여유를 활용하여 동시 처리(Parallel) 수를 4에서 8로 늘리고, 모델 로딩 한도를 상향합니다.
팀원 다수가 접속해도 병목 현상이 없도록 설정합니다.

Terminal (Alvin) 
brew install ollama
npm install -g pm2

# M4 Pro (64GB) 최적화 설정
# OLLAMA_NUM_PARALLEL="8": 동시 접속 8명까지 Context Swapping 없이 즉시 응답
# OLLAMA_MAX_LOADED_MODELS="2": Chat 모델과 Code 모델 동시 메모리 상주 가능
pm2 start "ollama serve" --name ollama-core \
  --env OLLAMA_HOST="0.0.0.0:11434" \
  --env OLLAMA_ORIGINS="*" \
  --env OLLAMA_NUM_PARALLEL="8" \
  --env OLLAMA_MAX_LOADED_MODELS="2" \
  --env OLLAMA_KEEP_ALIVE="24h"

# 메인 모델 (DeepSeek-R1 32B)
ollama pull deepseek-r1:32b

# 보조 모델 (Coding 전용, 선택)
ollama pull qwen2.5-coder:14b

pm2 save && pm2 startup

10. 확장 계획: Thunderbolt Cluster

향후 추가될 Mac mini(또는 동료의 Mac)를 썬더볼트 케이블로 연결하면, 별도 네트워크 장비 없이 40Gbps 내부망(Bridge Network)이 구성됩니다.

Thunderbolt Bridge

  • 1. Mac끼리 Thunderbolt 케이블 연결
  • 2. 설정 > 네트워크 > 썬더볼트 브리지 > IPv4 수동 설정
  • 3. Master(Alvin): 10.0.0.1
  • 4. Worker(New): 10.0.0.2
  • * 초저지연 로컬 추론 클러스터 완성

Worker Node 활용법

  • • Ollama Load Balancing: Nginx로 10.0.0.1과 10.0.0.2에 요청 분산
  • • Model Partition: Alvin은 Chat 모델(32B), Worker는 Code 모델(14B) 전담
