OpenClaw Setup v2 (macOS)

pm2 제거 + launchd 기반 OS Native 서비스 전환 가이드

Infrastructure Status

LaunchDaemons 전환 (pm2 제거)

필수

Before → After (아키텍처)

Before (pm2)

root → alvin(pm2) → ollama / sudo -u fern → pm2 → openclaw gateway

After (launchd)

LaunchDaemons → com.alvin.ollama(UserName=alvin) / com.fern.openclaw(UserName=fern)

보안 영향 분석

항목 pm2 (기존) LaunchDaemons (변경)
권한 경계 sudo 우회 혼재 OS 레벨 drop privileges
자동 재시작 pm2 의존 launchd native
로그인 영향 GUI 로그인 필요 가능 부팅 즉시 자동
샌드박스 호환 충돌 가능성 독립 세션 보장
감사 추적 불명확 Console.app 기반 명확

Step 0: 환경 정리 (Alvin) 안정성 

# Alvin 계정에서 Playwright 라이브러리 및 브라우저 데이터 완전 삭제
npm uninstall -g playwright
rm -rf ~/Library/Caches/ms-playwright

Step 1: pm2 제거 (Alvin + Fern) 안정성

launchd는 macOS 기본 내장 서비스 관리자입니다. 별도 설치가 필요 없습니다.

# Alvin
pm2 kill >/dev/null 2>&1 || true
pm2 unstartup >/dev/null 2>&1 || true
npm uninstall -g pm2
rm -rf ~/.pm2 ~/.config/pm2

# Fern
sudo -H -u fern zsh -lc 'pm2 kill >/dev/null 2>&1 || true'
sudo -H -u fern zsh -lc 'pm2 unstartup >/dev/null 2>&1 || true'
sudo -H -u fern zsh -lc 'npm uninstall -g pm2'
sudo rm -rf /Users/fern/.pm2 /Users/fern/.config/pm2

Step 2: Fern 런타임 구축 (Fern 계정) 필수 

# 1. 계정 전환 및 NVM/Node v24 원클릭 설치
su - fern
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
echo 'export NVM_DIR="$HOME/.nvm"\n[ -s "$NVM_DIR/nvm.sh" ] && \\. "$NVM_DIR/nvm.sh"' >> ~/.zprofile
source ~/.zprofile && nvm install 24 && nvm alias default 24

# 2. 필수 패키지 및 OpenClaw 초기화
npm install -g openclaw
openclaw onboard      # 가이드에 따라 API Key 및 샌드박스(/Users/fern/sandbox) 설정

Step 3: 네트워크 & 보안 (PF v4.5-ULTIMATE 유지) 필수 

# Fern SSH 차단
sudo dseditgroup -o create com.apple.access_ssh >/dev/null 2>&1 || true
sudo dseditgroup -o edit -a alvin -t user com.apple.access_ssh
sudo dseditgroup -o edit -d fern -t user com.apple.access_ssh >/dev/null 2>&1 || true

Step 4: 샌드박싱 (APFS + ACL) 필수 

# APFS 샌드박스 및 ACL
sudo chmod 700 /Users/alvin /Users/fern
sudo mkdir -p /Users/fern/sandbox
sudo chown fern:staff /Users/fern/sandbox && sudo chmod 700 /Users/fern/sandbox
sudo chmod +a "user:fern deny list,add_file,search,delete,add_subdirectory,writeattr,writeextattr,chown,file_inherit,directory_inherit" /Users/Shared
sudo chmod +a "user:fern deny list,add_file,search,delete,add_subdirectory,writeattr,writeextattr,chown,file_inherit,directory_inherit" /Volumes/*

v2 마스터 스크립트 (LaunchDaemons)

안정성

pm2 제거 후 LaunchDaemons로 무인 자동화 + 권한 격리

plist 파일 생성/등록 방식은 아래 스크립트에 포함되어 있습니다.

#!/bin/bash
set -euo pipefail

echo ">>> [5/5] 서비스 가동 (LaunchDaemons 전환 - 무인 자동화 및 격리)..."

# 1. 기존 pm2 프로세스 정리 (안전장치)
pm2 kill >/dev/null 2>&1 || true
sudo -H -u fern pm2 kill >/dev/null 2>&1 || true

# 2. alvin 계정용 Ollama 데몬 생성
sudo tee /Library/LaunchDaemons/com.alvin.ollama.plist << 'EOF' >/dev/null




    Label
    com.alvin.ollama
    UserName
    alvin
    RunAtLoad
    
    KeepAlive
    
    EnvironmentVariables
    
        OLLAMA_HOST
        127.0.0.1:11434
    
    ProgramArguments
    
        /bin/zsh
        -lc
        ollama serve
    
    StandardOutPath
    /tmp/ollama-out.log
    StandardErrorPath
    /tmp/ollama-err.log


EOF

# 3. fern 계정용 OpenClaw Gateway 데몬 생성
sudo tee /Library/LaunchDaemons/com.fern.openclaw.plist << 'EOF' >/dev/null




    Label
    com.fern.openclaw
    UserName
    fern
    GroupName
    staff
    WorkingDirectory
    /Users/fern/sandbox
    RunAtLoad
    
    KeepAlive
    
    ProgramArguments
    
        /bin/zsh
        -lc
        ulimit -u 512 && openclaw gateway
    
    StandardOutPath
    /Users/fern/sandbox/bot-out.log
    StandardErrorPath
    /Users/fern/sandbox/bot-err.log


EOF

# 4. 권한 부여 및 데몬 등록 (root 권한 필수)
echo ">>> plist 파일 권한 설정 및 launchctl 로드 중..."
sudo chown root:wheel /Library/LaunchDaemons/com.alvin.ollama.plist /Library/LaunchDaemons/com.fern.openclaw.plist
sudo chmod 644 /Library/LaunchDaemons/com.alvin.ollama.plist /Library/LaunchDaemons/com.fern.openclaw.plist

# 이전에 로드된 캐시가 있다면 언로드
sudo launchctl unload /Library/LaunchDaemons/com.alvin.ollama.plist >/dev/null 2>&1 || true
sudo launchctl unload /Library/LaunchDaemons/com.fern.openclaw.plist >/dev/null 2>&1 || true

# 데몬 로드 (시스템 부팅 시 즉시 실행 + 현재 즉시 실행)
sudo launchctl load -w /Library/LaunchDaemons/com.alvin.ollama.plist
sudo launchctl load -w /Library/LaunchDaemons/com.fern.openclaw.plist

echo "✅ v3.4(v2) 보안 배포 및 LaunchDaemons 등록 완료!"

🖥️ macOS GUI 보안 설정 가이드 선택

1. 외장 하드(/Volumes) 접근 제어 (GUI) 필수

  1. 외장 하드 아이콘 우클릭 > 정보 가져오기
  2. '소유권 무시' 체크박스 해제
  3. 목록 하단의 '+' 버튼을 눌러 fern 사용자 추가 후 권한을 '접근 불가'로 변경

2. Fern SSH 차단 여부 체크 (중요) 필수

  1. 시스템 설정 > 일반 > 공유 > 원격 로그인 이동
  2. '다음 사용자만:' 섹션에 alvin만 등록되어 있는지 확인

3. 샌드박스(100GB) 마운트 최종 확인 (GUI) 안정성

  1. Finder에서 /Users/fern/sandbox 이동
  2. Cmd+I (정보 가져오기) 실행
  3. 종류가 볼륨/드라이브이며 용량이 100GB인지 확인
