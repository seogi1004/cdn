모바일 모니터링은 스마트폰과 태블릿에서 운영에 필요한 핵심 기능을 바로 확인할 수 있도록 대시보드 조회, 알림 및 Web Push, 제니퍼 인사이트 채팅를 제공합니다. 모바일 브라우저에서 PWA 방식으로 홈 화면에 추가해 사용할 수 있습니다.

Beta 기능 안내모바일 모니터링 기능은 베타로 제공되며, 기능 및 화면 구성은 제품 업데이트에 따라 변경될 수 있습니다. 데스크톱 기능과 제공 범위 또는 업데이트 시점에 차이가 있을 수 있습니다.
1

대시보드 조회

  • 주요 실시간 차트와 서비스 상태를 모바일 화면에서 확인
  • 터치 기반 화면 탐색으로 필요한 운영 정보를 빠르게 조회
2

알림 및 Web Push

  • EVENT 알림 목록과 상세 내용 확인
  • 화면을 보고 있지 않을 때도 Web Push로 주요 EVENT를 수신
3

제니퍼 인사이트 채팅

  • 서버 LLM이 구성된 환경에서 모바일 제니퍼 인사이트 채팅 제공
  • 현재 상황을 자연어로 질문하고 분석을 이어서 확인

Beta 기능 안내이 페이지의 기능 역시 베타로 제공되며, 기능 및 화면 구성은 변경될 수 있고 데스크톱 기능과 업데이트 시점에 차이가 있을 수 있습니다.

이 페이지는 알림의 “조회”보다 Push 기반 선제 알림을 강조합니다. 제니퍼 인사이트는 서버 LLM 구성 환경에서 채팅을 제공한다는 조건을 함께 표기합니다.

도식화 가이드

우측 상단에 EVENT 발생 → View Server → 외부 푸시 서비스 → 모바일 알림 → 대시보드·제니퍼 인사이트 흐름을 배치합니다. 설치형 JENNIFER가 모바일로 직접 푸시하는 구조로 오해되지 않도록, 외부 푸시 서비스를 별도 단계로 표시합니다.

제약사항 · 설치형 환경 참고

대시보드·알림 조회와 Web Push의 조건을 분리해서 설명합니다. 고객사가 HTTP로 운영하거나 사설 인증서를 사용할 수 있으므로, Web Push에는 HTTPS 기반 보안 컨텍스트가 필요하고 사설 인증서는 모바일 기기에서 신뢰 설정이 필요하다는 점을 참고로 표기합니다.

또한 View Server에서 브라우저·OS의 외부 푸시 서비스로 아웃바운드 통신이 가능해야 하므로 폐쇄망에서는 Web Push 기능이 제한될 수 있습니다. 실제 지원 범위는 고객사 네트워크·인증서·브라우저 정책을 함께 확인합니다.

제니퍼 인사이트 채팅은 chat-report-server와 LLM 연결 구성이 필요합니다.

기술 기반 메시지

Spring 7 / Jetty 12 / Jakarta EE 11 / Servlet 6.1 현대화를 “Web Push가 이 버전 때문에 가능해졌다”는 직접 인과로 표현하지 말고, 보안 대응과 최신 웹 기능 확장을 함께 뒷받침하는 서버 기반으로 연결합니다.
