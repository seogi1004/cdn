Recommended IDE

1. 다운로드 및 설치

JetBrains 공식 사이트에서 무료 버전인 Community Edition을 다운로드합니다.

Download Page

* 운영체제(Windows/macOS/Linux)에 맞는 버전을 선택하세요.

2. 프로젝트 불러오기 (Import)

  1. IntelliJ 실행 후 Open 버튼을 클릭합니다.
  2. 소스 코드가 있는 폴더 안의 pom.xml 파일을 선택하고 Open을 누릅니다.
  3. Open as Project를 선택하여 Maven 프로젝트로 엽니다.
  4. 필요한 라이브러리가 다운로드될 때까지 기다립니다.

3. JDK 17 설정 (필수)

프로젝트가 Java 17 환경에서 빌드되도록 설정을 확인합니다.

  1. 메뉴: File > Project Structure... (단축키: Ctrl+Alt+Shift+S)
  2. Project Settings > Project > SDK를 17로 설정합니다.
  3. 없다면 Add SDK > Download JDK...에서 Amazon Corretto 17을 다운로드합니다.

4. JAR 파일 빌드 (Maven Install)

어댑터를 Jennifer Server에 배포할 수 있는 JAR 파일로 만듭니다.

  1. IntelliJ 우측 사이드바의 Maven 탭을 클릭합니다.
  2. Lifecycle을 펼치고 install을 더블 클릭합니다. (또는 터미널에서 mvn install 입력)
  3. 빌드가 성공하면(BUILD SUCCESS), 프로젝트 루트의 dist 폴더를 확인합니다.
생성 파일: dist/smtp-legacy-adapter-1.0.0.jar

Java 17 Compatible

이 코드는 javax.mail을 사용하여 이메일을 발송하며, Transport 연결 재사용을 통해 성능을 최적화했습니다. 

package com.aries.adapter.smtp

import com.aries.extension.data.EventData
import com.aries.extension.handler.EventHandler
import com.aries.extension.util.LogUtil
import com.aries.extension.util.PropertyUtil
import java.util.Properties
import javax.mail.Authenticator
import javax.mail.Message
import javax.mail.PasswordAuthentication
import javax.mail.Session
import javax.mail.Transport
import javax.mail.internet.InternetAddress
import javax.mail.internet.MimeMessage
import java.time.Instant

/**
 * SMTP Adapter for Legacy TLS Support (TLSv1.0, TLSv1.1)
 *
 * 설정을 통해 TLS 1.0/1.1을 사용하는 구형 SMTP 서버와 통신합니다.
 */
class SmtpAdapter : EventHandler {

    companion object {
        private const val ADAPTER_ID = "smtp_legacy"
        private const val DEFAULT_PORT = "587"
        private const val DEFAULT_SSL_TRUST = "*"
    }

    override fun on(events: Array) {
        val host = getConfig("smtp_host", null)
        val port = getConfig("smtp_port", DEFAULT_PORT)
        val username = getConfig("auth_user", null)
        val password = getConfig("auth_pass", null)
        val fromAddr = getConfig("from_addr", null)
        val toAddr = getConfig("to_addr", null)
        val sslTrust = getConfig("ssl_trust", DEFAULT_SSL_TRUST)

        if (host.isNullOrEmpty() || username.isNullOrEmpty() || password.isNullOrEmpty() || toAddr.isNullOrEmpty()) {
            LogUtil.error("SMTP Adapter configuration missing.")
            return
        }

        val props = Properties().apply {
            put("mail.transport.protocol", "smtp")
            put("mail.smtp.host", host)
            put("mail.smtp.port", port)
            put("mail.smtp.auth", "true")
            put("mail.smtp.starttls.enable", "true")
            // 핵심: TLS v1.0, v1.1 강제 활성화 요청
            put("mail.smtp.ssl.protocols", "TLSv1 TLSv1.1 TLSv1.2")
            
            if (!sslTrust.isNullOrEmpty()) {
                put("mail.smtp.ssl.trust", sslTrust)
            }
        }

        val session = Session.getInstance(props, object : Authenticator() {
            override fun getPasswordAuthentication(): PasswordAuthentication {
                return PasswordAuthentication(username, password)
            }
        })

        // 최적화: Transport 연결을 한 번만 맺고 재사용
        var transport: Transport? = null
        try {
            transport = session.getTransport("smtp")
            transport.connect() // Session의 Authenticator 사용

            for (event in events) {
                try {
                    val message = createMessage(session, event, fromAddr!!, toAddr)
                    // static send() 대신 인스턴스 메서드 사용으로 연결 재사용
                    transport.sendMessage(message, message.allRecipients)
                    LogUtil.info("SMTP Email sent: ${event.errorType}")
                } catch (e: Exception) {
                    LogUtil.error("Error sending individual message: ${e.message}")
                }
            }
        } catch (e: Exception) {
            LogUtil.error("SMTP Connection Error: ${e.message}")
        } finally {
            try {
                transport?.close()
            } catch (e: Exception) {
                // Ignore close error
            }
        }
    }

    private fun createMessage(session: Session, event: EventData, from: String, to: String): Message {
        val message = MimeMessage(session)
        message.setFrom(InternetAddress(from))
        if (to.contains(",")) {
            message.setRecipients(Message.RecipientType.TO, InternetAddress.parse(to))
        } else {
            message.setRecipient(Message.RecipientType.TO, InternetAddress(to))
        }
        message.subject = "[Jennifer] ${event.eventLevel}: ${event.errorType}"
        message.setContent(buildHtmlContent(event), "text/html; charset=utf-8")
        return message
    }

    private fun buildHtmlContent(event: EventData): String {
        val time = Instant.ofEpochMilli(event.time).toString()
        val msg = event.message ?: ""
        return """
            
            
                
[${event.eventLevel}] ${event.errorType}

                

                
Service: ${event.serviceName}

                
Time: $time

                
Message:
$msg

            
            
        """.trimIndent()
    }

    private fun getConfig(key: String?, defaultValue: String?): String? {
        return try {
            PropertyUtil.getValue(ADAPTER_ID, key, defaultValue)
        } catch (e: Exception) {
            defaultValue
        }
    }
}

JDK TLS Configuration Guide

Required

Java 17+은 기본적으로 TLS 1.0/1.1을 차단합니다. 코드를 적용하더라도 아래 JDK 설정을 변경하지 않으면 전송이 실패합니다.

방법 1: java.security 파일 수정 (권장)

  1. JDK 경로의 conf/security/java.security 파일을 엽니다.
  2. jdk.tls.disabledAlgorithms 항목을 찾습니다.
  3. 목록에서 TLSv1, TLSv1.1을 삭제합니다.

Before:

jdk.tls.disabledAlgorithms=SSLv3, TLSv1, TLSv1.1, RC4, DES, ...

After:

jdk.tls.disabledAlgorithms=SSLv3, RC4, DES, ...

방법 2: 실행 옵션 추가 (대안)

파일 수정이 어려운 경우, 별도 보안 파일을 만들어 실행 인자로 전달합니다.

  • enable_legacy_tls.security 파일 생성
  • 내용 작성: jdk.tls.disabledAlgorithms=SSLv3, RC4, DES, MD5withRSA
  • 실행 스크립트 수정:
-Djava.security.properties=/path/to/enable_legacy_tls.security
