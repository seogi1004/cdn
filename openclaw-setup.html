0. OpenClaw 온보딩 필수

처음 설치 시 openclaw onboard를 실행하면 아래 순서로 초기 설정이 진행됩니다.

①

API Key 입력

사용할 LLM 공급자(Gemini, OpenAI 등)의 API 키를 프롬프트에 입력합니다. 키는 ~/.openclaw/config.json에 암호화되어 저장됩니다.

②

Local Model 연결 (Ollama)

로컬 Ollama 서버(127.0.0.1:11434)가 감지되면 자동으로 DeepSeek 모델과 연결합니다. Ollama가 먼저 실행 중이어야 합니다.

③

Persona / System Prompt 설정

에이전트의 역할과 행동 지침을 정의하는 시스템 프롬프트를 입력합니다. 이후 "3. 하이브리드 페르소나" 섹션의 내용을 붙여넣기 하세요.

④

Workspace(샌드박스) 경로 지정

에이전트가 파일을 읽고 쓸 기본 작업 디렉터리를 지정합니다. /Users/fern/sandbox를 입력합니다.

⑤

설정 완료 및 첫 실행

온보딩이 완료되면 openclaw start 명령으로 에이전트가 대기 모드로 진입합니다. 이후 PM2로 상시 가동합니다.

1. 스킬셋 설치 필수

OpenClaw CLI가 플러그인을 직접 관리합니다. openclaw plugins install 명령어로 설치하세요. 

# 현재 설치된 플러그인 목록 확인
openclaw plugins list

브라우저 자동화 및 실무 스킬셋 플러그인을 설치합니다. 

# 브라우저 엔진 설치 (Playwright)
npm install -g @playwright/test
npx playwright install

# 실무 스킬셋 플러그인 설치
openclaw plugins install @openclaw/plugin-playwright
openclaw plugins install @openclaw/plugin-applescript
openclaw plugins install @openclaw/plugin-filesystem

설치 후 Gateway를 재시작하면 플러그인이 활성화됩니다. (pm2 restart fern-bot)

2. 에이전트 자동 실행 (PM2) 안정성

관리자(Alvin) 계정에서 Fern 계정 권한으로 에이전트를 영구 가동합니다.

# Alvin 계정에서 실행 (Fern 계정으로 샌드박스 진입 후 시작)
sudo -u fern zsh -lc 'pm2 start --name fern-bot --interpreter zsh -- zsh -lc "ulimit -u 512 && cd /Users/fern/sandbox && openclaw start"'
sudo -u fern pm2 save

💡 v3.4 소스코드 보호 Anchor 정책 필수

v3.4에서는 VPN 터널 및 RFC 1918 사설 IP 전면 차단을 추가하여 사내 소스코드 유출을 원천 봉쇄합니다. 

# 1. 전용 Anchor 파일 생성 (/etc/pf.anchors/fern)
sudo tee /etc/pf.anchors/fern << 'EOF'
# [필수] 로컬호스트: Ollama(11434) TCP 포트만 허용, 나머지 TCP 접근 차단
block drop out quick proto tcp from any to 127.0.0.1 port != 11434 user fern

# [필수] VPN 터널 원천 차단
block drop out quick on utun0 user fern
block drop out quick on utun1 user fern
block drop out quick on utun2 user fern
block drop out quick on utun3 user fern
block drop out quick on utun4 user fern
block drop out quick on ipsec0 user fern

# [필수] RFC 1918 사설 IP 대역 (사내망/내부망) 전면 차단
block drop out quick from any to 10.0.0.0/8 user fern
block drop out quick from any to 172.16.0.0/12 user fern
block drop out quick from any to 192.168.0.0/16 user fern

# [선택] mDNS(Bonjour) 등 내부망 탐색 차단
block drop out quick proto udp from any to any port 5353 user fern

# [선택] IPv6 내부망 차단 (외부 인터넷은 허용)
block drop out quick inet6 from any to fe80::/10 user fern
block drop out quick inet6 from any to fc00::/7 user fern
EOF

# 2. pf.conf 적용 및 문법 검증 (쌍따옴표 제거)
if ! grep -q 'anchor fern' /etc/pf.conf; then
  echo 'anchor fern' | sudo tee -a /etc/pf.conf >/dev/null
  echo 'load anchor fern from /etc/pf.anchors/fern' | sudo tee -a /etc/pf.conf >/dev/null
fi

# 3. 문법 검증 후 안전하게 리로드
if sudo pfctl -n -f /etc/pf.conf >/dev/null 2>&1; then
  sudo pfctl -f /etc/pf.conf && sudo pfctl -e
  echo '✅ PF 설정이 안전하게 적용되었습니다!'
else
  echo '🚨 PF 문법 에러 발생! /etc/pf.anchors/fern 파일을 확인하세요.'
fi

💾 1. APFS Quota & fstab 영구 마운트 (v3.4) 안정성

재부팅 시 샌드박스 볼륨이 기본 경로(/Volumes)로 자동 마운트되어 샌드박싱이 무력화되는 것을 방지합니다.

# 1. 샌드박스 볼륨 감지 및 생성
CID="$(diskutil info / | awk -F': *' '/APFS Container Disk|APFS Container Reference/ {print $2; exit}')"
sudo mkdir -p /Users/fern/sandbox
if ! diskutil list | grep -q "FernSandbox"; then
  sudo diskutil apfs addVolume "$CID" APFS FernSandbox -quota 100g
fi

# 2. fstab 등록 (UUID 기반 영구 마운트 지점 고정)
VOL_UUID=$(diskutil info "FernSandbox" | awk '/Volume UUID:/ {print $3}')
if [[ -n "$VOL_UUID" ]] && ! grep -q "$VOL_UUID" /etc/fstab 2>/dev/null; then
  echo "UUID=$VOL_UUID /Users/fern/sandbox apfs rw,nodev,nosuid" | sudo tee -a /etc/fstab >/dev/null
fi

# 3. 마운트 및 소유권 설정
sudo diskutil unmount "FernSandbox" || true
sudo diskutil mount -mountPoint /Users/fern/sandbox "FernSandbox"
sudo chown fern:staff /Users/fern/sandbox && sudo chmod 700 /Users/fern/sandbox

⚙️ 2. 리소스 및 프로세스 제한 (ulimit 강제 종속) 안정성

상시 가동 시스템의 가용성 보호(Fork Bomb 방지)를 목적으로 합니다.

# FernBot 가동 시 ulimit -u 512 강제 적용
sudo -u fern zsh -lc 'pm2 start --name fern-bot --interpreter zsh -- zsh -lc "ulimit -u 512 && cd /Users/fern/sandbox && openclaw start"'

📂 3. 공유 폴더 상속 ACL 차단 (최적화) 필수

에이전트가 관리자 홈이나 외장 드라이브를 스캔하지 못하게 하는 최소한의 울타리입니다.

# Shared 폴더 및 외장 하드 접근 거부 (최상단 루트에만 적용)
sudo chmod +a "user:fern deny list,add_file,search,delete,add_subdirectory,writeattr,writeextattr,chown,file_inherit,directory_inherit" /Users/Shared || true
sudo chmod +a "user:fern deny list,search,add_file,add_subdirectory,file_inherit,directory_inherit" /Volumes/* >/dev/null 2>&1 || true

보안 마스터 스크립트 (Verified V3.4)

안정성

VPN/사설망 차단 강화 + fstab 영구 마운트 + ulimit 강제 종속 통합 버전

#!/bin/bash
set -euo pipefail

# OpenClaw M4 Max Security Master Script (Verified & Refined V3.4)
ALVIN_HOME="/Users/alvin"
FERN_HOME="/Users/fern"
SANDBOX_MP="/Users/fern/sandbox"
SANDBOX_VOL="FernSandbox"
SANDBOX_QUOTA="100g"

echo ">>> [1/9] 홈 디렉토리 격리..."
sudo chmod 700 "$ALVIN_HOME" "$FERN_HOME"

echo ">>> [2/9] ACL 차단 적용 (성능/안정성 최적화)..."
sudo chmod +a "user:fern deny list,add_file,search,delete,add_subdirectory,writeattr,writeextattr,chown,file_inherit,directory_inherit" /Users/Shared || true
sudo chmod +a "user:fern deny list,search,add_file,add_subdirectory,file_inherit,directory_inherit" /Volumes/* >/dev/null 2>&1 || true

echo ">>> [3/9] APFS 100GB 샌드박스 볼륨 생성 및 fstab 영구 마운트..."
CID="$(diskutil info / | awk -F': *' '/APFS Container Disk|APFS Container Reference/ {print $2; exit}')"
if [[ -z "${CID}" ]]; then echo "ERROR: APFS Container 감지 실패"; exit 1; fi

sudo mkdir -p "$SANDBOX_MP"
if ! diskutil list | grep -q "$SANDBOX_VOL"; then
  sudo diskutil apfs addVolume "$CID" APFS "$SANDBOX_VOL" -quota "$SANDBOX_QUOTA"
fi

VOL_UUID=$(diskutil info "$SANDBOX_VOL" | awk '/Volume UUID:/ {print $3}')
if [[ -n "$VOL_UUID" ]] && ! grep -q "$VOL_UUID" /etc/fstab 2>/dev/null; then
  echo "UUID=$VOL_UUID $SANDBOX_MP apfs rw,nodev,nosuid" | sudo tee -a /etc/fstab >/dev/null
fi

sudo diskutil unmount "$SANDBOX_VOL" >/dev/null 2>&1 || true
if ! sudo diskutil mount -mountPoint "$SANDBOX_MP" "$SANDBOX_VOL"; then
  echo "ERROR: FernSandbox 마운트 실패! 볼륨 상태를 확인하세요." && exit 1
fi
sudo chown fern:staff "$SANDBOX_MP" && sudo chmod 700 "$SANDBOX_MP"

echo ">>> [4/9] SSH 원격 접속 원천 봉쇄..."
sudo dseditgroup -o create com.apple.access_ssh >/dev/null 2>&1 || true
sudo dseditgroup -o edit -a alvin -t user com.apple.access_ssh
sudo dseditgroup -o edit -d fern -t user com.apple.access_ssh >/dev/null 2>&1 || true

echo ">>> [5/9] PF 방화벽 정책 반영 (Syntax 교정 및 안전 검증)..."
sudo mkdir -p /etc/pf.anchors
sudo tee /etc/pf.anchors/fern >/dev/null <<'EOF'
# [필수] 로컬호스트: Ollama(11434)만 허용
block drop out quick proto tcp from any to 127.0.0.1 port != 11434 user fern
# [필수] VPN 터널 원천 차단 (사내 소스코드 유출 방지)
block drop out quick on utun0 user fern
block drop out quick on utun1 user fern
block drop out quick on utun2 user fern
block drop out quick on utun3 user fern
# [필수] RFC 1918 사설 IP 전면 차단
block drop out quick from any to 10.0.0.0/8 user fern
block drop out quick from any to 172.16.0.0/12 user fern
block drop out quick from any to 192.168.0.0/16 user fern
# [선택] mDNS/IPv6 차단
block drop out quick proto udp from any to any port 5353 user fern
block drop out quick inet6 all user fern
EOF

if ! grep -q 'anchor "fern"' /etc/pf.conf; then
  echo 'anchor "fern"' | sudo tee -a /etc/pf.conf >/dev/null
  echo 'load anchor "fern" from "/etc/pf.anchors/fern"' | sudo tee -a /etc/pf.conf >/dev/null
fi

if sudo pfctl -n -f /etc/pf.conf >/dev/null 2>&1; then
  sudo pfctl -f /etc/pf.conf
  sudo pfctl -e >/dev/null 2>&1 || true
else
  echo "ERROR: PF 구문 오류! 방화벽 로드 실패." && exit 1
fi

echo ">>> [6/9] Ollama 가동 (PM2 - Admin)..."
pm2 delete ollama-core >/dev/null 2>&1 || true
pm2 start --name ollama-core --interpreter bash -- bash -lc 'export OLLAMA_HOST=127.0.0.1:11434; ollama serve'
pm2 save

echo ">>> [7/9] FernBot 가동 및 ulimit 강제 종속..."
sudo -u fern zsh -lc 'pm2 delete fern-bot >/dev/null 2>&1 || true'
sudo -u fern zsh -lc 'pm2 start --name fern-bot --interpreter zsh -- zsh -lc "ulimit -u 512 && cd /Users/fern/sandbox && openclaw start"'
sudo -u fern zsh -lc 'pm2 save'

echo ">>> [8/9] ulimit 제한 설정..."
sudo -u fern zsh -lc "grep -q '^ulimit -u 512' '${FERN_HOME}/.zshrc' 2>/dev/null || echo 'ulimit -u 512' >> '${FERN_HOME}/.zshrc'"

echo ">>> [9/9] 보안 검증 결과 출력..."
echo ">>> [DONE] V3.4 보안 마스터 배포 완료"

Ollama가 꺼져 있을 때 — 빠른 복구

FernBot이 Ollama에 연결하지 못하면 로컬 모델 추론이 불가합니다. 아래 순서대로 복구하세요. 

# ① Ollama 프로세스 확인 (아무것도 안 뜨면 꺼진 것)
ps aux | grep -v grep | grep 'ollama serve'

# ② PM2로 Ollama 재기동 (Alvin 계정에서 실행)
pm2 restart ollama-core

# ③ 기동 확인 (online 상태이면 정상)
pm2 status

# ④ API 응답 테스트
curl -s http://127.0.0.1:11434/api/tags | python3 -m json.tool

💡 ollama-core가 PM2 목록에 없다면 아래 "Ollama 시작" 섹션의 수동 등록 절차를 따르세요.

🦙 Ollama 서버 관리 필수

① 현재 상태 확인 

# PM2 등록 여부 및 실행 상태 확인
pm2 status

# Ollama 프로세스 직접 확인
ps aux | grep -v grep | grep ollama

# API 포트 리스닝 여부 확인
lsof -i :11434

# 로드된 모델 목록 조회
curl -s http://127.0.0.1:11434/api/tags | python3 -m json.tool

② PM2로 시작 (권장 — 재부팅 후에도 자동 복구) 

# [케이스 A] 이미 PM2에 등록되어 있는 경우 → 재시작
pm2 restart ollama-core

# [케이스 B] PM2 목록에 없는 경우 → 최초 등록
pm2 delete ollama-core > /dev/null 2>&1 || true
pm2 start --name ollama-core --interpreter bash -- bash -lc \
  'export OLLAMA_HOST=127.0.0.1:11434; ollama serve'
pm2 save

# 부팅 시 자동 시작 등록 (최초 1회만)
pm2 startup   # 출력된 sudo 명령어를 그대로 복사해서 실행

③ 임시 수동 시작 (테스트용)

터미널을 닫으면 함께 종료됩니다. 디버깅 목적으로만 사용하세요.

# 백그라운드 데몬으로 올라마 실행
OLLAMA_HOST=127.0.0.1:11434 ollama serve &

# 또는 포그라운드로 실행 (로그를 직접 보고 싶을 때)
OLLAMA_HOST=127.0.0.1:11434 ollama serve

④ DeepSeek 모델 확인 및 다운로드 

# 현재 로컬에 있는 모델 목록
ollama list

# DeepSeek R1 모델이 없으면 Pull (약 4~20GB, 버전에 따라 다름)
ollama pull deepseek-r1:14b   # 14B 파라미터 권장 (M4 Max 64GB)
# 또는
